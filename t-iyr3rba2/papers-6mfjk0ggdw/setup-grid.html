학생별 진도표 켜기

컴퓨터에서 하시는 게 편해요 · 코드가 바뀌면 이 순서대로 다시 한 번 (최근 수정 11/20 20:15: 이름이 바뀐 DAY의 예전 기록도 같은 DAY 칸에 합쳐 보여 줌 · 추가 권한 창은 안 떠요)

1코드 복사

아래 파란 버튼을 누르면 필요한 코드가 통째로 복사돼요. 열어 보거나 고칠 필요 없어요.

2Apps Script 열기

구글 드라이브에서 daily english 시트를 열고, 위쪽 메뉴 확장 프로그램 → Apps Script를 눌러요.

3바꿔 붙이기

열린 화면 가운데 코드 칸을 한 번 클릭하고 Ctrl + A(맥은 ⌘ + A)로 전부 선택 → Ctrl + V(⌘ + V)로 붙여 넣어요.

그다음 Ctrl + S(⌘ + S)로 저장해요.

4새 버전으로 배포

오른쪽 위 파란 배포 → 배포 관리 → 연필 모양 수정 → 버전 칸에서 새 버전 고르기 → 배포.

'새 배포'가 아니라 꼭 '배포 관리'예요. 그래야 학생 앱 주소가 그대로 유지돼요. 권한 확인 창이 뜨면 선생님 계정으로 '허용'을 누르세요.

5확인

선생님 보드로 돌아가 학생별 진도표 → 를 눌러 표가 나오면 끝이에요.
