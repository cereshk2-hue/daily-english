# 천재 4단원 데일리 실전 10회분 — 다른 창 작업용 안내

## 들어 있는 파일
- `천재4단원_데일리실전_01회.docx` ~ `10회.docx` : 회차별 시험지(2단) + 정답 및 해설(새 페이지부터)
- `천재4단원_데일리실전_문항은행.xlsx`
  - **문항은행** 시트: 200문항 전체. 열은 회차, 번호, 형식, 영역, 유형, 고난도, 발문, 지문·보기, 선지①~⑤, 정답, 서술형 정답, 해설, 오답 분석, 핵심, 출처, 검수 메모
  - **회차별 정답** 시트: 앱 OMR 정답 입력용
  - **구성 요약** 시트: 회차별 영역 수와 정답 번호 분포

## 구성 원칙
- 원본은 너른터 천재(소) 4단원 1~11회, 242문항입니다.
- **제거한 문항**
  - 거의 같은 문제
  - 자유 영작처럼 채점이 애매한 서술형
  - 복수 정답("모두 고르시오") 문항
- **수정한 문항**: 정답이 두 개였거나 오타·비문이 있던 문항입니다. 엑셀 '검수 메모' 열과 해설 [검수] 줄에 적어 두었습니다.
- **회차 구성**
  - 회차당 20문항: 객관식 17~18문항(1번부터)과 서술형 2~3문항(마지막 번호들)
  - 영역: 본문 8~9, 대화문 4~5, 문법 3~4, 어휘 1~2 (서술형 포함)
  - 객관식 정답 번호: 회차마다 ①~⑤가 3~4개씩 나오고, 같은 번호가 3번 연속 나오지 않습니다.
- **신규 고난도(★) 2문항**: 4회 18번(일기 전체 종합 이해), 8회 18번(어법 개수)
- **서술형**: 정답이 하나로 정해지는 것만 남겼습니다. '서술형 정답' 열의 문자열과 그대로 비교하면 됩니다.
  - 마침표·대소문자 처리는 앱 설정에 맞춰 주세요.
  - 허용 답안은 해설의 [주의] 줄에 적어 두었습니다(예: 9회 문항의 !/., didn't/did not).

## 다른 창에서 이어서 할 때
- 이 README와 엑셀 파일을 함께 올리면, 문항·정답·해설을 그대로 다시 불러올 수 있습니다.
- 모의고사 데일리 학습에 섞을 때는 '영역'과 '유형' 열로 필터해 원하는 만큼 뽑아 쓰면 됩니다.
