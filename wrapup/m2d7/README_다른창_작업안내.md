## 구성 원칙
- 원본은 너른터 중2 동아(윤정미) 7과 변형문제 200문항입니다.
  - 본문 1~4: Fallas, Midsummer, 망자의 날, Fur Rondy
  - 대화문 1~3
  - 문법 1(가주어 It ~ to부정사), 문법 2(5형식 목적격 보어)

  - 거의 같은 문제 26개

- **수정한 문항**: 51·54·60·67·163번 등. 엑셀 '검수 메모' 열과 해설 [검수] 줄에 적어 두었습니다.
- **회차 구성**
  - 회차당 20문항: 객관식 17~18문항(1번부터)과 서술형 2~3문항(마지막 번호들)

- **서술형**
  - 원본 중 정답이 하나로 정해지는 14문항(모두 문법)
  - 본문·대화문 신규 6문항: 회차마다 1문항씩 넣었습니다.
- **신규 고난도(★) 2문항**: 7회 18번(네 축제 종합), 8회 18번(가주어·5형식 어법 개수)
