## 학생 화면
- **오늘의 학습**: DAY 세트. 단계는 순서대로 열리고, 끝낸 단계는 눌러서 다시 풀 수 있어요(점수는 처음 기록 유지). 문제 하나 풀 때마다 저장돼서 중간에 나가도 그 문제부터 이어서 해요.
- **본문**: 원문과 해석. 해석은 가렸다 켰다 할 수 있어요.
- **유형별 연습**: 아무 유형이나 골라 자유롭게 연습. 점수와 문자에는 들어가지 않아요.
- DAY를 다 끝내면 **문자로 보내기** → 학생 폰 문자앱이 결과가 채워진 채로 열리고, 학생이 전송을 누르면 보내져요.

## 선생님 보드 (통합 화면)
저장소 첫 주소 `https://<아이디>.github.io/<저장소>/` 가 **선생님용 보드**예요. 학년 탭 → 출판사별 카드 → 단원마다 **열기 / 학생 링크 복사**.
- "열기"로 들어간 단원 화면에는 **← 전체 목록** 버튼이 생겨요. 학생 링크로 들어온 학생에게는 안 보여요.
- 새 단원 폴더를 추가하면 보드에 자동으로 나타나요 (`python3 tools/build.py` 로 다시 만들 때).
- **컴퓨터에 앱으로 설치**: 크롬이나 엣지로 보드 주소를 열고 → 화면의 "컴퓨터에 앱으로 설치" 버튼, 또는 주소창 오른쪽 설치 아이콘(크롬: ⋮ 메뉴 → 전송, 저장, 공유 → 앱으로 설치 / 엣지: ⋯ → 앱 → 이 사이트를 앱으로 설치). 설치하면 바탕화면·시작 메뉴에 아이콘이 생기고 별도 창으로 열려요.
- 보드 주소는 학생에게 주지 마세요. 학생에게는 단원별 학생 링크만 보내면 돼요.

## 1. 선생님 번호 넣기 (1분)
각 폴더의 `data/….js` 파일 맨 위쪽 `teacherPhone: '',` 을 `teacherPhone: '010-1234-5678',` 처럼 바꿉니다.
비워 두면 학생이 문자앱에서 받는 사람을 직접 넣어야 해요.

## 2. GitHub Pages에 올리기
1. github.com 에서 새 저장소 만들기 (예: `daily-english`, Public)
2. **Add file → Upload files** 로 이 zip 안의 **모든 파일과 폴더**(index.html, manifest.webmanifest, sw.js, 아이콘 2개, 단원 폴더들)를 통째로 끌어다 놓고 Commit
3. **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 선생님 보드는 `https://<아이디>.github.io/<저장소>/`, 학생용 주소는
   - 6과: `https://<아이디>.github.io/<저장소>/m1-chunjae-L6/`
   - 동아 6과: `https://<아이디>.github.io/<저장소>/m1-donga-yoon-L6/`
   - 중2 동아 7과: `https://<아이디>.github.io/<저장소>/m2-donga-yoon-L7/`
   - 중3 지학사 7과: `https://<아이디>.github.io/<저장소>/m3-jihak-min-L7/`

## 3. 다음 과 만들 때
폴더 하나를 복사하고 `data/` 안의 파일만 새 과 내용으로 바꾸면 됩니다. 작성 규칙은 이 문서 맨 아래 "데이터 작성 규칙"에 있어요. 고친 뒤에는 `node tools/validate.js data/새파일.js` 로 검사하고 `python3 tools/build.py` 로 다시 만드세요.

## 알아 두기
- 진도와 점수는 **학생 휴대폰 브라우저에만** 저장됩니다. 다른 폰이나 다른 브라우저로 들어오면 처음부터예요.
- 문자는 학생 폰의 문자앱을 여는 방식이라 **학생이 전송 버튼을 눌러야** 실제로 보내집니다.

## 데이터 작성 규칙
```
   pick  : 'There {is|are} no grass.'  → 중괄호 안 첫 번째가 정답 (화면에서는 섞여 나옴)
   tf    : [문장, true/false, 해설]
   verb  : s 의 ___ 자리에 (v) 를 알맞게 바꿔 쓰기. a 는 정답 목록(여러 개 허용)
   error : [[ ]] 로 감싼 부분이 ①②③④ 선택지. w = 틀린 곳 번호(0부터), fix = 고친 표현
   order : lines 를 본문 순서대로 적으면 화면에서 섞여 나옴
   scramble : en 을 단어 단위로 섞음
   mc    : opts 첫 번째가 정답 (화면에서는 섞여 나옴)
   일치·불일치 : type 'mc', title '일치·불일치'. opts 첫 번째가 정답, box: ['❷'] 는 문제 아래에 보여 줄 본문 단락,
                 per: [[선택지 해석, 근거(본문 일부 또는 목록), 판정], ...] 를 opts 순서대로
   tf    : 5번째 칸에 근거 문장(본문 일부)을 넣으면 해설에 근거 문장과 해석이 나옴
   order/insert : flow: ['한글 전개', ...] 를 lines 순서대로 넣으면 "글의 전개"가 나옴
   검사 : node tools/validate.js data/xxx.js (근거 문장이 본문에 있는지까지 검사)
```
